# Multi-Source Noisy Fraud Labels

- **Source:** Zhang et al., 2021, Fraud Detection under Multi-Sourced
  Extremely Noisy Annotations.
- **DOI:** https://doi.org/10.1145/3459637.3482433
- **Method:** Label aggregation and correction from multiple noisy annotation
  sources.
- **Finding:** Additional label sources can improve learning under noisy
  annotations.
- **DAC relevance:** Provides a principled direction for resolving conflicting
  signatures if independent labels are permitted later.
- **Caveat:** The DAC project currently has one observed target and therefore
  cannot reproduce this setup without importing prohibited information.
