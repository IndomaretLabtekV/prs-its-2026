# DAC 2026 Ultimate Baseline Notebook — Implementation Plan

**Goal:** Produce one self-contained, report-ready Kaggle notebook that follows the official DAC 2026 answer-sheet chapters, computes every empirical claim at runtime, and writes a validated `submission.csv`.

**Architecture:** A sequential notebook owns the full workflow. Small pure functions implement official scoring, reporting, preprocessing, validation, calibration, fairness, and plotting. Runtime dictionaries preserve facts, metrics, tables, predictions, and experiment metadata. Expensive fitting is deferred to Kaggle; local checks compile cells and execute only synthetic metric cases.

**Stack:** Python, pandas, NumPy, SciPy, scikit-learn, CatBoost, XGBoost, matplotlib, seaborn, IPython; all are standard Kaggle packages.
