# DAC 2026 V9 Design — Naik dari 0.96833 ke 0.98+

## Status

Target: LB 0.98+ (butuh +56 TP di top-5% OOF dari 7792 → ≥7848).
Strategi: Kaggle T4x2, artifact-first (reuse V8), matriks kandidat kecil,
gate promosi V8 dipakai ulang verbatim. Estimasi run: ~45 menit.

## Problem

V8 membuktikan rerank boundary jenuh (12/12 challenger gugur di gate gain +
fold-win). Error analysis OOF (lokal, reproducible) menemukan:

- 205/217 FP "tenggelam dalam" (skor > skor rank-7758) — bukan masalah boundary.
- Penalti post-hoc subgroup KM / kdkc-2101-2103 / dati2-309 GAGAL (+1 TP lalu
  negatif): 1418 fraud top-K se-subgroup, fraud rate subgroup 0.567 vs 0.498.
  Model sudah Bayesian-optimal untuk fitur yang ada.
- ~3800 grup fitur-identik berlabel campur → ceiling riil < 1.0.
- Ranking loss (YetiRank/LambdaRank) tidak feasible penuh: limit query GPU
  (1023 / 10000) vs grup 32k; versi chunked diuji lokal dan degradasi
  (-0.037 NR). Dikeluarkan dari matriks utama V9.
- Fold 2 & 4 lemah persisten di semua seed (diagnostik, bukan kandidat).

Kesimpulan: satu-satunya tuas yang belum dicoba adalah **kapasitas model**
(fitur interaksi eksplisit + seed diversity + bobot label-noise), BUKAN
rerank, BUKAN penalti, BUKAN ranking loss.

## Goals

1. Reuse artefak V8 tervalidasi (fold, OOF/test scores, hierarchy, meta) —
   tanpa retrain base yang sudah ada.
2. Uji 4 kandidat baru yang masing-masing menyentuh kapasitas model.
3. Promosikan hanya yang lolos 10 gate V8 vs V3 control (OOF murni).
4. Satu submission primer + audit bundle lengkap.

## Non-goals

- No pairwise/surgical reranker baru (V8 menutup jalur ini).
- No ranking-loss objective (bukti lokal: infeasible/degradasi).
- No LB probing dalam bentuk apa pun; seleksi 100% OOF.
- No claim ID / row position sebagai fitur; no demographic post-processing.
- No hyperparameter grid (semua setting = warisan tervalidasi V7/V8).

## Evidence Baseline (terkunci)

- V3 control: NR 0.973027, 7792 TP, 216 legit audit, AP 0.82512 (LB 0.96833).
- Anchor 2127/2026: 7772 / 7776 TP. Stack: 7780 TP (gugur vs V3).
- Seed-mean V4 (cat_mean): 7795 TP (+3) — sinyal seed diversity positif kecil.
- Oracle ceiling: +216 TP. Target 0.98: +56. Target 0.985: +98.

## Architecture

### 1. Artifact-first (wajib lolos validasi kontrak V8)

Reuse dari `v8-checkpoint/v8_artifacts`: fold assignments (5 fold, overlap 0),
`v3_oof`/`v3_test` (V3 control beku), prediksi base 2127/2026, hierarchy, meta.
Jika artefak invalid → fail loudly (jangan retrain diam-diam).

### 2. Matriks kandidat (4 entri, fixed, predeclared)

| ID | Kandidat | Pelatihan baru | Rasional |
|---|---|---|---|
| C0 | V3 control (fallback) | tidak ada | baseline + LB saat ini |
| C1 | Seed-mean3 (2127+2026+3407) | 1 model (3407, 5 fold) | V4 cat_mean +3 TP; seed ketiga = diversitas murah |
| C2 | CatBoost + fitur interaksi (seed 2127) | 1 model × 5 fold | interaksi eksplisit `RISK_SUBGROUP × {age_band, los_band, burden_bin}` tempat CatBoost CTR lemah (OR dari 3 kondisi) |
| C3 | CatBoost + fitur interaksi (seed 2026) | 1 model × 5 fold | replikasi seed kedua; 2 fold-win butuh dua seed |

(C4 mixed-weight DIBATALKAN saat smoke: flag grup-campur vakuous di bawah
StratifiedGroupKFold — tiap signature utuh dalam satu fold sehingga tidak
pernah muncul di outer folds. Dicatat sebagai temuan negatif.)

Catatan C2/C3: `RISK_SUBGROUP = (typeppk==KM)|(kdkc∈{2101,2103})|(dati2==309)`.
Fitur baru tepat 4 kolom (flag + 3 interaksi binned), semua dari kolom yang
diizinkan; tanpa encoding baru.

### 3. Gates (8 gate; formula dan threshold verbatim V8, vs C0 OOF)

NR gain ≥ 0.001 (~8 TP); ≥3 fold-win; confirmation gain ≥ 0;
worst fold ≥ -2; AP delta ≥ -0.001; OOF churn ≤ 0.08;
gain/100 swap ≥ 1.0; test churn ≤ min(0.10, 1.25·OOF+0.015).
Gate 9-10 stress V8 DIBUANG (tidak ada reranker yang transportnya perlu
diukur); cascade tanpa min-stress: confirmation → primary gain →
swap efficiency → test churn → kompleksitas. Gagal semua → C0 + laporan gate.

### 4. Kalibrasi & submission

Sigmoid monotonik pasca-ranking (order-preserving), satu `submission_v9.csv`,
`selected_config.json` + provenance + pernyataan ID/row-exclusion.

## Outputs (`v9_artifacts/`)

`artifact_manifest.json`, `v9_feature_audit.csv`, `v9_candidate_registry.csv`,
`v9_primary_fold_deltas.csv`, `v9_test_churn.csv`,
`v9_scores.npz`, `selected_config.json`, `submission_v9.csv`.

## Failure Handling

- Artefak invalid → stop. GPU fail → retry GPU 0 CTR-reduced (pola V7).
- C2/C3 divergen (NaN) → kandidat gugur, run lanjut.
- Tidak ada yang lolos → C0 tetap disubmit ulang HANYA jika checksum identik
  dengan submission_v8 (hemat submit); jika tidak identik, investigasi dulu.

## Behavioral Verification (warisan V8, minus stress/surgical)

Tie netral, disjointness signature, kontrak artefak,
eksklusi proxy (tidak relevan — C2/C3 full features, dicatat eksplisit),
kelengkapan encoding, registry tepat 4 entri sekali, determinisme seleksi +
fallback C0, kontrak submission.
