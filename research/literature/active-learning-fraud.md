# Streaming Active Learning for Fraud

- **Source:** Carcillo et al., 2018, Streaming Active Learning Strategies for
  Real-Life Credit Card Fraud Detection.
- **DOI:** https://doi.org/10.1007/s41060-018-0116-z
- **URL:** https://arxiv.org/abs/1804.07481
- **Method:** Active querying under delayed labels and limited investigator
  feedback.
- **Finding:** Selective feedback can improve top-ranked fraud precision.
- **DAC relevance:** Suggests an operational path beyond static supervised
  learning, but it requires new labels and cannot be simulated honestly from
  the current files.
